# 自建微信群活码系统

线下推广用：一个固定网址展示「当前有效群二维码」，群满后到后台换图即可，**印刷物料永不重印**。
支持多群管理与自动切换（某群扫码达阈值自动跳下一个未满群）。

## 目录结构
```
huoma/
├── server.py            # 本地服务
├── generate_qr.py       # 生成线下印刷用的静态二维码
├── requirements.txt
├── templates/
│   ├── index.html       # 落地页（用户扫码看到）
│   └── admin.html        # 后台（你管理群码）
├── static/qrcodes/      # 群二维码图片存放处
└── data/                # 配置与群数据（自动生成）
```

## 本地跑通
```bash
pip install -r requirements.txt
python3 server.py
```
- 落地页： http://localhost:8080/
- 后台：   http://localhost:8080/admin?token=huoma123

## 使用流程（群内专属版：网站只在群里发）
本系统的落地页**不包含任何网站外链**，只负责把人拉进群；网站入口只在群内发布。
1. 浏览器打开后台，上传微信「群设置 → 群二维码」的截图/PNG（建议先建好 2~3 个群）。
2. 配置页面标题/副标题（应用链接、福利链接字段本版已不使用，可留空）。
3. 运行 `python3 generate_qr.py` 生成线下印刷二维码（指向 http://localhost:8080），
   把它印到海报/传单/易拉宝上。用户扫码 → 进群 → 在群里看群公告拿网站链接。
4. 群满 100 人前，到后台上传新群码并「设为生效」，或开启自动切换（默认阈值 90）。

## 不进群不给看：访客门禁怎么做
仅靠「只在群里发链接」不够——群里任何人转发链接，外面人也能看。要做到真防漏，二选一：

**A. 口令门（轻量，推荐起步）**
网站加一个密码页，正确口令才放行进站；口令只在群里发、定期更换（如每周换）。
- 纯前端实现最简单，但口令写在页面里可被高手翻源码，只挡「顺手转发」的大众用户。
- 要真防破解，口令校验必须放**服务端**（下面 B 思路通用）。

**B. 服务端校验（真正防漏，按你的网站技术栈做）**
- 若网站也是 Python/Flask：在路由前加一层 `@login_required` 校验 cookie/Token，Token 由群内专属链接带参进入（如 `?t=群专属码`），且定期失效。
- 若用 Nginx 反代：用 `auth_request` 指向一个校验服务，未带有效 Token 返回 401 跳转进群引导页。
- 若用 企业微信客户群：可用「进群即关注/客户联系」能力做身份绑定，体验最顺，但需企业微信。

## 部署到公网（让真实用户能扫）
本地只能你自己看。要让线下用户扫码，需把本服务部署到一台有公网地址的服务器：
- 最简单：部署到任意支持 Python 的云服务器 / 轻量应用，用域名指向，例如 `https://huoma.你的域名.com/`
- 然后重新生成印刷二维码：
  ```bash
  python3 generate_qr.py "https://huoma.你的域名.com/"
  ```
- 生产环境建议：用 gunicorn 跑 `server.py`、前面加 Nginx；并通过环境变量设置口令：
  ```bash
  ADMIN_TOKEN="你的复杂口令" PORT=8080 gunicorn -w 2 -b 0.0.0.0:8080 server:app
  ```

## 安全提示
- 默认后台口令为 `huoma123`，**部署前务必改为复杂字符串**（环境变量 `ADMIN_TOKEN`）。
- 后台地址不要公开到落地页，避免被恶意上传/删除。
